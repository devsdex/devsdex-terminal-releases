# devsdex terminal

Cliente SSH y SFTP nativo para macOS 14 o posterior, en Apple Silicon.

**Estado:** lanzamiento en preparación. La descarga pública se habilitará después de completar la firma Developer ID, notarización y las verificaciones de distribución. No hay binarios públicos disponibles todavía.

- Web: https://devsdex.github.io/devsdex-terminal-releases/
- Soporte y reportes: https://github.com/devsdex/devsdex-terminal-releases/issues
- Idiomas: español e inglés.

Este repositorio contiene únicamente sitio, novedades y versiones. El código fuente de la aplicación es privado.

No incluyas contraseñas, claves privadas, contenido de terminal ni información sensible en las incidencias.
